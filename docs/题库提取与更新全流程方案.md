## 一、 整体技术架构与目录映射

驾校一点通电脑版采用 **Electron + SQLite + Vue** 架构，其题库系统由“云端更新包”和“原厂内置库”双轨构成：

```
D:\Program Files (x86)\jxedt\
│
├── app\node_modules\bak\question_banks\    <-- 【云端下载题库目录】
│   └── xc.db                               <-- 小车(xc)最新题库（下载后存放于此，明文题目，无文字解析）
│
├── resources\app\db\
│   └── jxedt_user.db                       <-- 【原厂全量数据库】（全车型3.5万题，含官方详解，XOR加密）
│
├── resources\app\dist\electron\
│   └── renderer.js                         <-- 【前端核心逻辑】（包含解密函数、城市筛选、抽题算法）
│
└── 题库导出\                                <-- 【自动化流水线导出产物目录】
```

### 核心数据库职责对比：
| 数据库文件 | 大小 | 记录数 | 加密状态 | 作用与特点 |
| :--- | :---: | :---: | :---: | :--- |
| `question_banks/xc.db` | ~72 MB | 12,190 | 明文 | **最新题库**。包含全国+全省市最新考题、名师技巧口诀、原画视频直链、全网错题率。 |

## 二、 逆向解密算法（XOR 还原）

在原厂 `jxedt_user.db` 中，题干、选项和详解均被存储为加密二进制 Blob。  
通过逆向 `renderer.js` 第 751544 字符处的 `jiemi` 函数，获取其底层算法与密钥：

### 1. 算法特征
* **算法类型**：循环异或（XOR）
* **固定密钥**：`jxedt_pc_client_secret`（ASCII 字节流）
* **字符编码**：UTF-8

### 2. Python 解密标准实现：
```python
SECRET_KEY = b"jxedt_pc_client_secret"

def decrypt_val(val):
    if val is None:
        return ""
    if isinstance(val, str):
        return val
    if isinstance(val, (bytes, bytearray)):
        out = bytearray(len(val))
        for i in range(len(val)):
            out[i] = val[i] ^ SECRET_KEY[i % len(SECRET_KEY)]
        try:
            return out.decode('utf-8')
        except UnicodeDecodeError:
            return out.decode('gb18030', errors='ignore')
    return str(val)
```

## 三、 数据库表结构与核心字段规范

### 1. 题目主表：`web_note`
* `ID` (INTEGER)：题目全局唯一编号。
* `kemu` (INTEGER)：科目代码（`1`: 科目一；`2`: 科目二常识；`4`: 科目四）。
* `Type` (INTEGER)：题型代码（`1`: 判断题；`2`: 单选题；`3`: 多选题）。
* `Question` (TEXT)：题干内容（部分题目题干包含 `<img src=...>` 行内图标）。
* `An1` ~ `An4` (TEXT)：选项 A、B、C、D 的文字内容。
* `AnswerTrue` (TEXT)：标准答案（`1`~`4` 代表 A~D；多选为组合如 `124` 代表 ABD）。
* `explain` / `best_explain_new` (BLOB/TEXT)：官方权威考点详解（需解密）。
* `error_rate` (REAL)：**全网学员真实答错率**（0.0 ~ 1.0，如 0.25 代表 25% 错率）。
* `diff_degree` (INTEGER)：难度评级（1 ~ 5 星）。
* `cityid` (INTEGER)：城市/省份归属代码（`0`: 全国通用题；`>0`: 各省市地方题）。
* `gs` (TEXT)：车型代码标签（`xc`: 小车；`hc`: 货车；`kc`: 客车；`mtc`: 摩托车等）。
* `media_url` / `sinaimg` (TEXT)：题图或动画视频 CDN 直链。

### 2. 名师技巧表：`t_app_question_black_board`
* `question_id` (INTEGER)：关联 `web_note.ID`。
* `voiceSubtitles` (TEXT)：**名师秒杀口诀与答题技巧**（如：“*题干中看到逃逸犯罪的，直接找终生*”）。

### 3. 原画视频解析表：`t_question_video_explain`
* `question_id` (INTEGER)：关联 `web_note.ID`。
* `video_url` (TEXT)：高清 MP4 名师讲解视频在线直链。

## 四、 城市考题过滤算法与排序机制

软件客户端展示的题量与全国全量合集的对应关系由以下 SQL 算法决定：

```sql
SELECT * FROM web_note
WHERE kemu = 1                                         -- 科目一
  AND (',' || gs || ',') LIKE '%,xc,%'                 -- 小车类型
  AND (category IS NULL OR category IN (0, 1, 2))      -- 正规考题
  AND cityid IN (0, :province_id, :city_id)            -- 全国题 + 本省题 + 本市题
ORDER BY CAST(strTppe AS INT) ASC, ID ASC;             -- 严格对齐客户端“顺序练习”顺序
```

> **以无锡为例**：
> * 全国通用题（`cityid = 0`）：2,339 题
> * 江苏无锡地方题（`cityid = 25` 或 `182`）：74 题
> * **考生实考题量合计**：$2339 + 74 = \mathbf{2413}$ 题

## 五、 自动化提取流水线使用指引

已在根目录下部署一键提取脚本：`D:\Program Files (x86)\jxedt\tiku_pipeline.py`。

### 1. 常用命令示例：

* **当驾校一点通更新了新题库时（一键同步最新小车题库）**：
  ```bash
  python "D:\Program Files (x86)\jxedt\tiku_pipeline.py"
  ```
* **提取摩托车题库（mtc）**：
  ```bash
  python "D:\Program Files (x86)\jxedt\tiku_pipeline.py" --car mtc
  ```
* **提取货车题库（hc）**：
  ```bash
  python "D:\Program Files (x86)\jxedt\tiku_pipeline.py" --car hc
  ```

### 2. 输出结果清单：
流水线执行后将在 `题库导出/` 目录下生成：
1. `驾校一点通_{car}_题库导出.xlsx`：带工作表的标准 Excel 考题表。
2. `驾校一点通_{car}_干净题库.db`：已解密合并的单表 SQLite 干净数据库。

## 六、 离线智能刷题器更新流程

若后续题库有大规模题目变动，更新 `无锡科目一_易错题智能刷题器.html` 仅需两步：
1. 运行 `tiku_pipeline.py` 导出最新数据；
2. 运行 `python scratch/generate_practice_app.py`，即可重新生成带有最新考题的自包含单个 HTML 网页刷题器。
