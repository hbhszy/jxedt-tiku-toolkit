# 🚗 驾校一点通题库逆向解密与智能备考工具箱 (jxedt-tiku-toolkit)

本项目针对《驾校一点通》PC 客户端（Electron + Vue + SQLite）进行题库逆向解密、城市题库清洗提取，并提供一套**零外部依赖、单文件离线可用**的智能备考刷题器（内置**上班无痕摸鱼模式**与**紧急老板键**）。

---

## ✨ 核心特性

### 1. 💻 离线单文件智能刷题器 (`index.html`)
* **🔥 黄金去重核心集（376 题）**：在剔除 1,600+ 道常识水题的基础上，进一步筛除正反重复问法的“孪生题”，只保留真正有陷阱的独立考点母题。
* **📍 江苏/无锡地方特产题（74 题）& 2025 新规/英文缩写专攻（27 题）**：100% 覆盖“轻微道路交通事故视频快处”与现场医疗急救多选题。
* **⚡ 智能断点续刷 & 一键斩题（快捷键 `K`）**：
  * 自动按分类独立记忆上次刷到的题号与位置，重新打开或切换分类时直接续刷。
  * 遇到已掌握的简单题按 `K` 键直接斩掉隐藏，越刷越薄；按 `U` 键一键跳至当前列表第一道未答题。
* **🎯 全真 100 题模拟考试（45 分钟）**：按车管所真实比例（单选 60 题 + 判断 40 题，含地方题）随机组卷，交卷后错题自动收入错题本。
* **🐟 真·无痕摸鱼模式 + 🚨 紧急老板键**：
  * 按 `M` 键一键进入无痕伪装，顶栏伪装为编辑器文件标签（`README.md` / `metrics_Q4.xlsx` / `spec_validator.ts`），默认收起题库分类栏（按 `H` 键展开/隐藏）。
  * **代码 IDE 皮肤**：题干与选项转为 `12.5px` 低对比度暗灰色 `@description / @param` JSDoc 注释，上下自动包裹带行号（`1~31`）与彩色语法高亮的真实 TypeScript 业务代码。
  * **配图防窥**：题目配图自动缩小变灰，鼠标悬停时才临时放大恢复彩色。
  * **紧急老板键（波浪键 `` ` `` / `X` / `Esc`）**：0 延迟全屏切换为逼真的《2026年度部门业务数据统计与预算执行进度表.xlsx》并自动暂停视频。

### 2. 🔓 原厂题库 XOR 逆向解密与自动化导出流水线 (`tiku_pipeline.py`)
* 自动解密原厂 `jxedt_user.db`（循环异或密钥 `jxedt_pc_client_secret`）中的 3.5 万条官方权威详解。
* 融合云端最新题库 `xc.db` 的全网真实错题率、名师口诀（`voiceSubtitles`）与高清视频讲解直链，一键导出 Excel / CSV / JSON。

## 🚀 快速开始

### 方式一：直接刷题（零安装）
1. **普通模式**：直接双击根目录下的 `index.html`（或冲刺包内的 `01_...html`）。
2. **无地址栏独立摸鱼窗口（推荐）**：双击运行根目录下的 **`启动无地址栏摸鱼窗.bat`**，会自动调用本机 Edge / Chrome 的 `--app` 模式打开**无地址栏、无书签栏、无标签页**的独立窗口，并自动进入代码伪装模式。
3. **在线部署（GitHub Pages）**：将本仓库推送到 GitHub 后，在仓库 `Settings -> Pages` 中选择 `main` 分支根目录，即可通过在线网址在手机或办公电脑随时访问。

### 方式二：运行题库提取流水线
当本地安装了《驾校一点通》客户端并下载了最新题库包后：
```bash
pip install -r requirements.txt
python tiku_pipeline.py --jxedt-dir "D:\Program Files (x86)\jxedt" --car xc
```
* 提取货车题库：`python tiku_pipeline.py --car hc`
* 提取摩托车题库：`python tiku_pipeline.py --car mtc`

## ⌨️ 刷题器快捷键速查

| 快捷键 | 功能说明 |
| :---: | :--- |
| `A` / `B` / `C` / `D` 或 `1`~`4` | 选择对应选项（多选题选满后按 `Enter` 提交） |
| `←` / `→` / `空格` | 上一题 / 下一题 |
| `K` / `Delete` | **一键斩题**（将已掌握的题标记隐藏，越刷越薄） |
| `U` | **跳至未答**（一键跳到当前列表第一道还没做的题） |
| `M` | 开启 / 关闭 **无痕摸鱼模式** |
| `H` | 在摸鱼模式下 **展开 / 隐藏顶部分类筛选栏** |
| `` ` `` (左上角波浪键) / `X` / `Esc` | **紧急老板键**（瞬间全屏切换为 Excel 财务报表并暂停视频） |
